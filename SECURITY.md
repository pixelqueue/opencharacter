# Security

The engine evaluates formulas and actions from packs and character files, so treat a bug that
lets a file run code, read outside its data, or hang the engine as a security issue.

## Reporting a vulnerability

Report it privately through
[GitHub's security advisories](https://github.com/pixelqueue/opencharacter/security/advisories/new),
not as a public issue. Include the package and version, and a file or input that shows the
problem. You'll get a reply within a week.

## Supported versions

Fixes go into the latest release of each package.

# Packs

One folder per game, and one folder per pack inside it (`packs/<game>/<pack>/`, pack ID
`<game>-<pack>`, version starting at 0.1.0). Layout and rules: [AGENTS.md](../AGENTS.md) and the spec's
[packs chapter](../packages/spec/docs/packs.md). Every pack declares its license in `pack.yaml` and
ships its own `LICENSE`. [LICENSE](LICENSE) (CC0) covers anything here outside a pack.

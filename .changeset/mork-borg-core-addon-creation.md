Creation is open to add-on packs. The `class` start draws the class among the classes offered (`random`, a d6 over the core six) instead of indexing a d6 into them, and each class feature is drawn among the class's options (the Royalty's second a d5 over the five left, drawn rather than counted on from the first), so an add-on class and its features come up in random starts. A feature that brings a weapon grants it into the hidden `features.weapons` (the weapon is `fromFeature`, off the starting table) and creation adds it, instead of a list of the core options. The guided start offers each item the starting tables give as a pick among its type's content, add-on gear included, recommending the table's; the random starts keep the book's tables. The `classRoll`, `feature` and `feature2` steps are gone.

A class's new `startingScroll` field (the Esoteric Hermit's) gives it the random starting scroll, instead of a check of the Hermit's ID.

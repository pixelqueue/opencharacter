`get-better` runs a class's own part of getting better: a class with the new `getsBetter` field has an unlisted `get-better-part` action (the Gutterborn Scum's second specialty), so a homebrew class can add one. The Scum's steps are at `classPart/specialty` and `classPart/second`, after a `class` choice.
